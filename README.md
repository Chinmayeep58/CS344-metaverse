# Virtual Reality Based Earthquake Training with Blockchain Certification

## Overview

This repository contains the implementation of a **Virtual Reality Based Earthquake Training with Blockchain Certification** system developed as part of a research project at IIIT Vadodara.

The project aims to enhance earthquake preparedness through immersive and interactive virtual reality training. Traditional preparedness methods often rely on reading materials and instructional guidelines, which may not adequately simulate real emergency situations. The proposed system enables users to experience a realistic earthquake scenario within a safe virtual environment, allowing them to practice essential safety procedures such as identifying safe locations and performing the *Drop, Cover, and Hold On* technique.

To ensure authenticity and provide verifiable proof of participation, the system issues blockchain-certified completion certificates to successful participants.

---

## Research Objectives

* Develop a realistic virtual reality environment for earthquake preparedness training.
* Train users in recommended earthquake safety procedures.
* Assess the effectiveness of VR-based training compared to conventional learning methods.
* Implement blockchain-based certification for secure and verifiable credential issuance.

---

## Methodology

The training workflow consists of the following stages:

1. The user enters the virtual environment.
2. An earthquake simulation is initiated.
3. Objects and surroundings react to seismic activity.
4. The participant performs appropriate safety actions.
5. User performance is evaluated based on preparedness criteria.
6. A blockchain-certified completion certificate is generated for successful participants.
